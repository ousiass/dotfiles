# Ousiass デザインガイド準拠（docs への追記テンプレ）

既存のデザイントークン文書があれば、その中の 1 節として貼る。無ければ `docs/design/ousiass-design-guide.md` の本文にする。

````markdown
## Ousiass デザインガイド準拠

本プロダクトの UI は Ousiass 共通デザインガイド（brand-guide）に準拠する。ガイドが正であり、本書は値を複製しない。

- 正: https://ousiassllc.github.io/brand-guide/ （トークン可視化: https://ousiassllc.github.io/brand-guide/tokens-preview.html ）。該当節は `#typography`（見出し）・`#scrollbar`（スクロールバー）
- 参照した時点: <YYYY-MM-DD>（brand-guide `<コミット短縮 SHA>`）
- ライト / ダークの両方に対応する
- ガイドにない部品・値・モーションは使わない。必要なものは「ガイド未収載」に挙げ、ガイドへの追加を先に提案する

### トークン参照

値はガイドの定義をそのまま取り込む。本書では名前で参照する。

| 区分 | 使うトークン | 使いどころ |
|---|---|---|
| 色（コア） | `--ink` `--bone` `--mute` `--surface` `--border` `--accent` `--accent-soft` | <例: 背景は `--bone`、カードは `--surface`、主操作は `--accent`> |
| フォーカス | `--focus` | フォーカスリング、フォームの focus のみ |
| 状態色 | `--success` `--warning` `--danger` `--info` | <例: インラインアラート、ステータスピル> |
| タイポ | サイズ `xs`〜`3xl` / Regular・SemiBold | <例: 本文 `base`。見出しのサイズは下の「見出し」表で役割ごとに決める。SemiBold は見出しとボタンのみ> |
| 角丸・余白 | `--r-*` `--s-*` と間隔レシピ（`--gap-*` `--pad-card*`） | <例: カード `--r-lg` + `--pad-card`> |
| アイコン | Iconoir `--icon-sm` / `--icon-md` / `--icon-lg` | <例: ナビは 20、ボタン内は 16> |
| モーション | `--motion-*` `--ease-*` | <例: モーダル出現は `--motion-slow`、フェードイン `--motion-fade-in`> |
| レイアウト | `--bp-*` `--z-*` | <例: ドロワーは `--z-drawer`> |

プリズム（`--prism-*`）はロゴ・キービジュアルのみ。UI 部品には使わない。

### 見出し

見出しタグ（文書の意味構造）と表示サイズ（視覚的な役割）は独立に指定する。タグごとにサイズを固定しない。H1 は必須ではなく、H1 なしで h3 / h4 から始める画面（既存シェルへの埋め込みなど）も書いてよい。サイズはスケールのトークン名で書き、役割クラスで指定する。

| 役割 | 見出しタグ（意味構造） | サイズ（スケールのトークン） | 指定方法 |
|---|---|---|---|
| <例: ページ見出し> | <例: h3（既存シェル内のため H1 なし）> | <例: `xl`> | <例: 役割クラス `.page-title`> |
| <例: セクション見出し> | <例: h4> | <例: `lg`> | <例: 役割クラス `.section-title`> |

- H1 の有無・開始レベル: <例: シェルが H1 を持つため本画面は h3 から。／ H1 あり>
- 階層を飛ばす箇所: <無ければ「なし」。あれば文脈上の理由>

### スクロール領域

コンテンツをスクロールする領域（`overflow: auto` 等）を挙げる。見た目・優先関係・例外はガイドのスクロールバー規定に従い、本書に値を写さない。range スライダーの規定は使わない。

| 領域 | 方向（縦 / 横 / 両方） | 領域名（フォーカス時の名前） | 備考 |
|---|---|---|---|
| <例: 一覧テーブル> | <例: 両方> | <例: 「プロジェクト一覧」> | <例: 横は狭い幅のときだけ> |

- ネイティブスクロールを維持し、バーの常時非表示・独自 JS ドラッグへの置き換えはしない
- ブラウザ差（Firefox の近似）・OS のオーバーレイ・forced-colors での OS 標準への切り替えは、ガイド上の許容。画面ごとに確認した環境と結果は検証記録に残す

### 採用する部品

ガイドの部品名で列挙する。画面仕様・コンポーネント仕様からはこの名前で参照する。

| 優先度 | 部品（ガイドの名称） | 使う画面 |
|---|---|---|
| P0 | <例: トップナビ / ドロップダウン / 右ドロワー> | <画面名> |
| P1 | <例: ページネーション / 検索フィールド> | <画面名> |
| P2 | <例: オンボーディング / コーチマーク（`--ink` グレーのパルス）> | <画面名> |

### ガイド未収載の部品・案件固有部品

| 部品 | 扱い | 定義の場所 |
|---|---|---|
| <例: 独自の予約ウィジェット> | 案件固有（P3 の独自ウィジェット方針） | <案件ガイド / 該当ドキュメント> |
| <例: ◯◯> | ガイドへ追加を提案。承認まで使わない | <brand-guide の Issue / PR> |

### 逸脱

ガイドから外れる箇所。無ければ「なし」。

| 箇所 | ガイドの定め | 逸脱の内容 | 理由 | 承認 |
|---|---|---|---|---|
| なし | | | | |
````

## 書き方の規則

- トークンは名前で書く（`--s-4`）。hex や px の値を本書に写さない（値が二重管理になりズレる）
- 部品は P0〜P3 の名称で書く。ガイドにない名称を作らない
- 「準拠宣言」「参照した時点」「ガイド未収載」「逸脱」の 4 つは省かない。画面にスクロール領域があれば「スクロール領域」、見出しがあれば「見出し」も省かない
- 逸脱は承認が取れたものだけ「承認」欄を埋める。取れていなければ逸脱として使わず「ガイド未収載・追加提案」に回す
