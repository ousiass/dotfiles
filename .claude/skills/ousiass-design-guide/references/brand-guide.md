# Ousiass UI デザインガイド 要約

正は brand-guide。本ファイルはその要約であり、食い違ったらガイドが正。

- 公開ページ: https://ousiassllc.github.io/brand-guide/ （トークン可視化: `tokens-preview.html`）
- リポジトリ: `ousiassllc/brand-guide`
- 要約の取り込み時点: `73d8cf6`（色・フォント・サイズ・UI 確定、ダーク背景・スイッチ・スライダー追加、`--mute` を Light / Dark で分離 2026-11-05）
- ガイドの README は「下書き」と表記している。値の確定状況はページ上の表記が正

全プロダクト共通。ライト / ダークの両方が必須。UI はほぼ無彩色で、静かで余白の多い画面を基本にする。
**ガイドにない部品・値・モーションは使わない。** 必要なら先にガイドへ追加する。プロダクト専用ウィジェットは案件ガイドで定義し、共通ガイドに発明しない。

## 1. 色

### コアトークン

| トークン | Light | Dark | 用途 |
|---|---|---|---|
| `--ink` | `#050505` | `#ffffff` | 文字・ロゴ・主要アイコン |
| `--bone` | `#f5f5f4` | `#050505` | ページ背景 |
| `--mute` | `#6b6b6e` | `#8b8b8e` | 補助テキスト・キャプション（`--bone` / `--surface` 上で AA 4.5:1 以上。本文の長文には使わない） |
| `--surface` | `#ffffff` | `#141414` | カード・パネル |
| `--border` | `#e7e7e5` | `#2a2a2a` | 罫線・区切り |
| `--accent` | `#050505` | `#f5f5f4` | 主ボタン・リンク・選択状態（インク色そのもの） |
| `--accent-soft` | `#e7e7e5` | `#2a2a2a` | ホバー・選択背景 |
| `--focus` | `#4a72d0` | `#60a5fa` | フォーカスリング（プリズム blue を薄く借用） |

`--mute` は Light / Dark で値が異なる。キャプション・補助用。通常テキストとして AA 4.5:1（`--bone` / `--surface` 上）を満たす。

フォーカスリング: `2px solid var(--focus)` + `outline-offset: 2px`。フォームの focus は `--ring`（`--focus` を 40%）を使う。

### 状態色（くすませた無彩色寄り）

| トークン | Light | Dark | 用途 |
|---|---|---|---|
| `--success` | `#3d5c4a` | `#8fafa0` | 完了・成功 |
| `--warning` | `#7a6a3a` | `#c4b87a` | 注意 |
| `--danger` | `#7a4545` | `#c49a9a` | エラー・破壊的操作 |
| `--info` | `#4a5a6a` | `#9aabbc` | お知らせ |

ステータスのピル・バッジ: 文字 `var(--状態)`・枠 `color-mix(in srgb, var(--状態) 40%, transparent)`・地 `color-mix(in srgb, var(--状態) 10%, transparent)`・`--r-full`。使える色相は上記 4 トークンだけ（ピンク・ローズ等は禁止。中立の「下書き」だけは `--mute`）。

状態はアイコン＋文言＋状態色で伝える。色だけで意味を伝えない。鮮やかな原色は使わない。

### プリズム（キービジュアル専用）

`--prism-violet` `#8b6ad4`/`#a78bfa` → `--prism-blue` `#4a72d0`/`#60a5fa` → `--prism-cyan` `#3aaaba`/`#22d3ee` → `--prism-green` `#3d9a7a`/`#34d399` → `--prism-yellow` `#b8a24a`/`#fbbf24`（Light/Dark）。

- 使ってよいのはロゴ・ヒーロー・キービジュアルだけ
- ボタン・リンク・入力欄・バッジ・チャート・モーションには使わない
- 唯一の例外: フォーカスリングで blue を薄く借りる（`--focus`）

### ダーク背景

- ページキャンバス: `--bone` = `#050505`（ほぼ黒）
- パネル／カード／サイドバー: `--surface` = `#141414`
- 禁止: 真っ黒 `#000` / `#000000` の直置き（コントラストが強すぎて「静か」が崩れる）

## 2. タイポグラフィ

| 用途 | フォント | CSS |
|---|---|---|
| 英字・UI 英語・日本語 | Sora + Noto Sans JP | `font-family: Sora, "Noto Sans JP", sans-serif` |
| コード・桁を揃える数値 | JetBrains Mono | `font-family: "JetBrains Mono", ui-monospace, monospace` |

フォントはすべて SIL OFL。OFL 以外は持ち込まない。

### サイズスケール（本文 16px 基準）

| トークン | px | 行間 | 用途 |
|---|---|---|---|
| `xs` | 12 | 1.6 | 注記・バッジ |
| `sm` | 14 | 1.7 | 補足・表・ボタン小 |
| `base` | 16 | 1.8 | 本文・ボタン |
| `lg` | 18 | 1.7 | リード文・h4 |
| `xl` | 24 | 1.5 | h3 |
| `2xl` | 32 | 1.4 | h2 |
| `3xl` | 40 | 1.3 | h1・ヒーロー |

### ウェイト

- Regular (400): 本文・リンク・ナビ・フォーム
- SemiBold (600): **見出しとボタンのみ**（ボタン以外のナビ・リンクには使わない）
- Bold (700) 以上を多用しない。14px 未満を本文に使わない
- 日本語の長文は行間 1.8 前後。英語の見出しの字間は 0〜0.02em

## 3. 形・余白・線

### 角丸

`--r-none` 0 / `--r-sm` 4（タグ・チェック）/ `--r-md` 8（入力・ボタン）/ `--r-lg` 12（カード）/ `--r-xl` 16（モーダル）/ `--r-full` 9999（ピル・アバター）。

### 余白（4px 基準）

`--s-1` 4 / `--s-2` 8 / `--s-3` 12 / `--s-4` 16 / `--s-6` 24 / `--s-8` 32 / `--s-12` 48 / `--s-16` 64。
目安: 部品内 8–12 / 部品間 16–24 / セクション間 48–72（標準 `--gap-section` 72）。

### 線と影

- 既定: `--stroke` = `1px solid var(--border)`（カード・入力・区切り）
- 強調: `1px var(--mute)`（チェックボックス外枠など）
- 空状態・ドロップ領域: `1px dashed`
- 影: `--shadow-modal` = `0 1px 2px rgba(0,0,0,.06)` を**モーダルのみ**。カードは影なし

### 間隔レシピ（名前付きトークン）

| UI | 値 |
|---|---|
| メニュー / ナビ項目 | 項目間 8（`--gap-menu`）・高さ 40（`--menu-item-h`）・左右 12（`--menu-pad-x`、余裕があれば 16）。選択肢リストは項目間 4（`--gap-option`） |
| グリッド | 標準 16（`--gap-grid`）・広い画面/大きいカード 24（`--gap-grid-lg`）・密 12（`--gap-grid-dense`） |
| フォーム | ラベル→入力 6〜8（`--gap-label`）・入力→補足 4（`--gap-help`）・項目→項目 16（`--gap-field`） |
| 見出し | h1/h2 の下 24（`--gap-h1`/`--gap-h2`）・h3 の下 12（`--gap-h3`）・見出し→本文 8〜12（`--gap-heading-body`）・段落間 16（`--gap-para`） |
| カード | padding 24（`--pad-card`）・小さいカード 16（`--pad-card-sm`）・カード内のまとまり同士 24（`--gap-card-section`） |
| ボタン列・インライン | 8（`--gap-inline`） |
| セクション | 標準 72（`--gap-section`）・スマホ/密な画面 48（`--gap-section-sm`） |

## 4. UI 部品（基本）

- **フォーム**: 入力 高さ 40 / padding 12 / `--r-md` / 1px `--border` / `--surface` 地。textarea・select（ネイティブを同じ見た目に）・チェックボックス（18px・`--r-sm`・外枠 `--mute`）・ラジオ・スイッチ（下記「スイッチ」）・スライダー（下記「スライダー」）。エラーは入力下に文言。無効は opacity .5
- **ボタン**: 主（`--accent` 地・`--bone` 字）/ サブ（透明・1px `--border`）/ ゴースト / 危険（`--danger`）。SemiBold。`--r-md`。小は高さ 32。disabled は opacity .4。テキストリンクは Regular・下線 `--mute`
- **進捗**: track `--accent-soft` / fill `--accent` / 6px / `--r-full`。スピナーは 20px・2px（track `--accent-soft`・先端 `--accent`）
- **ステータスピル**: 完了・保留・エラー・情報・下書き。状態色の細枠＋薄い地。文言必須
- **インラインアラート**: お知らせ / 成功 / 注意 / エラーの 4 種。アイコン＋見出し＋本文。出現はフェードイン 320ms、消去はフェードアウト 240ms
- **トースト**: 画面下中央（端から 24）・高さ 40・ピル・`--ink` 地に `--bone` 字。3 秒（アクション付き 5 秒）で自動消去。同時 1 つ（新しいものが前を置き換え）。1 行の短文。アクションは 1 つまで（SemiBold「元に戻す」）。エラー詳細・フォーム検証・確認・破壊的操作には使わない（モーダル / インラインアラート）。トークン案: `--toast-h` 40 / `--toast-duration` 3s / `--toast-duration-action` 5s / `--toast-offset` 24px
- **スナックバー**: 画面下（端寄せ可）・`--surface` + border・やや長め・戻せる操作の結果（アーカイブしました＋元に戻す）。迷ったら「戻せる作業結果 → スナック、一瞬の確認 → トースト」
- **空状態**: 破線 border・`--r-lg`・padding 48/24・アイコン（`--icon-xl` 32 可）＋文言＋主ボタン
- **テーブル**: 見出し行 SemiBold 12 `--mute` ＋下線 1px。本文 Regular 14。数値列は JetBrains Mono 右寄せ。行ホバー `--accent-soft`。padding 上下 10 / 左右 12（compact は 6 / 8）。トークン: `--table-pad-y` `--table-pad-x` `--table-pad-y-compact` `--table-pad-x-compact` `--table-head-size` `--table-body-size` `--table-row-hover` `--table-divider`
- **リスト**: テキストリスト項目間 8（`--list-gap`）/ 記号→文字 10（`--list-marker-gap`）。番号は Mono `--mute`。設定行は最小高さ 48（`--list-row-h`）・左右 16（`--list-row-pad-x`）・区切り 1px。2 行リストはタイトル Regular＋`--mute` キャプション（間 2 `--list-title-caption-gap`・行間 12 `--list-two-line-gap`）
- **カード**: `--surface` + 1px `--border` + `--r-lg`、影なし。入れ子パネルは `--bone` + `--r-md`
- **タブ**: 下線 2px `--accent`。**セグメント**: `--accent-soft` 地＋`--surface` の選択面
- **オーバーレイ**: 基本は**中央モーダル**（`--r-xl`・`--shadow-modal`、確認・破壊的操作）。共有・短い選択肢はボトムシート可。**モーダル・シートとも外側（スクラム）クリックで閉じる**。スクラムはオーバーレイと一緒にフェード

### スイッチ

- サイズ: トラック 36×20、つまみ 14、角丸 full
- OFF: `accent-soft` + `border` / ON: `accent`（つまみは `bone`）
- フォーカス: `--ring`
- ラベル: Regular 15（SemiBold にしない）
- OS／ブラウザ標準トグル禁止

### スライダー

- トラック高 4、角丸 full。充填 `--accent`／未充填 `--accent-soft`
- つまみ 16 円、`surface` + 1px `border`
- フォーカス: `--ring`
- `accent-color` だけに頼らない。track／thumb を明示スタイル
- OS／ブラウザ標準の range 禁止
- 値表示は Mono `--mute` 可

## 5. モーション

基本は「静かだけど動きがある」。静か・短く・目的があるときだけ動かす。

| トークン | 値 | 用途 |
|---|---|---|
| `--motion-fast` | 120ms | フォーカス等 |
| `--motion-base` | 180ms | ホバー（色/背景のみ） |
| `--motion-slow` | 280ms | モーダル出現・シート（下から）・リップル |
| `--motion-fade-in` | 320ms | 出現（`--ease-out`） |
| `--motion-fade-out` | 240ms | 退出（`--ease-in`） |
| `--ease-out` | `cubic-bezier(0.2,0.8,0.2,1)` | |
| `--ease-in` | `cubic-bezier(0.4,0,1,1)` | |
| `--ease-in-out` | `cubic-bezier(0.4,0,0.2,1)` | |

Do: 状態変化・出現/退出を伝えるときだけ / opacity＋小さな移動（4–8px）/ ホバーは色・背景のみ ≤180ms・フォーカスは即時〜120ms / ボタンとクローズ（アイコンボタン）の押下は小さくリップル（クリック点から円がファン・280ms ease-out）/ スクラムはオーバーレイと一緒にフェード。

Don't: 装飾だけのループ・視差・大きな移動 / バウンス・スプリング・scale ポップ（使うなら最大 1.02）/ UI 上のプリズム（虹色）モーション / 300ms を超える UI トランジション / reduced-motion を無視する。

`prefers-reduced-motion: reduce`: 装飾的な動き（移動・スライド）は無効化。必要な opacity フェードは ≤100ms またはなし。スピナーなど処理中表示は維持。

## 6. P0 骨格

- **トップナビ**: 高さ 56 / border-bottom 1px / 左右 16–24 / ロゴ左・操作右 / リンクは Regular `--mute`、現在は `--ink`
- **サイドナビ**: 幅 240 / 項目高さ 40 / gap `--gap-menu` 8 / active = `--accent-soft` + `--ink`
- **モバイルナビ**: リンクを畳んでハンバーガー → 左ドロワー。スクラム/外側タップで閉じる。トップバー高さ 52–56・ドロワー幅 約 78%・ナビリンクは Regular
- **パンくず**: `--mute` リンク + 現在は `--ink`・区切り `›`・gap 8・sm 14
- **ドロップダウン**: panel `--surface` + border + `--r-md`・padding 4・min-width 180・項目 高さ 36–40 / padding 10–12 / ホバー `--accent-soft`・danger は `--danger` 文字のみ
- **ツールチップ**: 12px / padding 6×10 / `--r-sm` / fade-in 320ms・ホバー/フォーカス・非対話（ボタン・リンク禁止）。**ポップオーバー**: タイトル＋アクション・外側クリックで閉じる・dropdown より情報多く modal より軽い
- **右ドロワー**: 幅 min 320 / 85%・スクラム付き・外側クリックで閉じる・reduced-motion はフェードのみ。ドロワー＝持続するサイド文脈（詳細・フィルタ）、ボトムシート＝短い選択肢（共有など）。混同しない
- **ブレークポイント**: `--bp-sm` 640 / `--bp-md` 768 / `--bp-lg` 1024 / `--bp-xl` 1280。カラムはモバイル 4 / タブレット 8 / デスクトップ 12。ガターはモバイル `--s-4`、デスクトップ `--s-6`
- **z-index**: `--z-base` 0 / `--z-dropdown` 100（dropdown・tooltip・popover）/ `--z-sticky` 200 / `--z-drawer` 300 / `--z-modal` 400 / `--z-toast` 500
- **アイコン**: [Iconoir](https://iconoir.com)（MIT）。サイズ `--icon-sm` 16 / `--icon-md` 20 / `--icon-lg` 24（`--icon-xl` 32 は empty state のみ）。ストローク ≈1.5・`currentColor`。ブランドロゴは別（Iconoir ではない）。実装は Iconoir の SVG / パッケージから取得する

## 7. P1 部品

日付・時刻ピッカー（native-styled の `.fld`、カレンダーは popover・セル 32・今日 = `--accent`）/ ファイルアップロード・ドロップゾーン（破線 border・`--r-lg`・padding 24–28・ドラッグ中 `--accent-soft` + `--accent` 破線）/ 検索（左アイコン md・右クリア・候補は dropdown 相当 `--z-dropdown`）/ ページネーション（高さ 36・`--r-md`・現在 `--accent`）と「もっと見る」（無限スクロールの代わりに明示ボタン）/ ステップ・ウィザード（円 28・線 1px・完了 = `--accent` + ✓・現在ステップ名だけ SemiBold）/ アコーディオン（native `<details>`・summary SemiBold・body Regular `--mute`）/ 通知バッジ数（`--accent` 地 + `--bone` 字・11px Mono・min 18・99+ 可・ドットのみの未読も可）/ スライダー（§4「スライダー」。キーボード操作可）/ タグ入力（chips: `--accent-soft` + border + `--r-full`・入力は枠なし・Enter またはカンマで追加）。

## 8. P2 部品

- **コマンドパレット**: 中央オーバーレイ・外側スクラムクリックで閉じる・結果行はメニュー行高・`--accent-soft` 選択・キーボードヒントはフッターに静かに
- **データテーブル上級**: ソート見出し SemiBold 12 `--mute`（ソート中は `--ink`）/ フィルタはチップ行 / 行チェック → 一括バー（選択数＋アクション）
- **ツリー・ネストリスト**: ネストは左ボーダー＋インデント・開閉は `details/summary`・行高はメニュー行に合わせる
- **カレンダー（月表示）**: 今日 = `--accent-soft` + SemiBold・イベントは小さな `--info` ドット
- **チャート**: 系列色はほぼ無彩色の状態色（`--success` `--warning` `--info` `--mute` `--ink`）。プリズム禁止。余白 `--pad-card-sm`・凡例と図の間 8–12・軸とグリッドは `--border` のみ・塗りつぶしグラデ禁止・系列は最大 4〜5（超えたらグルーピングかテーブルへ）
- **スケルトン**: プレースホルダは `--accent-soft` の角丸バー・パルスは任意（reduced-motion では静止）・実コンテンツの骨格に合わせる
- **オンボーディング / コーチマーク**: スポットライトは対象ラッパーに **`--ink` グレーのベースリング（約 50%）＋広がって薄れるパルス（box-shadow）＋外側ディム（約 40%）**。リップルはボタン側。**focus 青は使わない**（reduced-motion では見える静止の ink リングのみ）。チップは `--surface` カード（ツールチップより情報多め）・同時に 1 つ・「ステップ n / m」「スキップ」「次へ」
- **印刷・PDF**: ink on bone（ダークテーマのまま出さない）/ ナビ・ドロワー・FAB・テーマ切替・トーストは `@media print` で非表示 / ページ余白 12–16mm・カード影なし・枠は 1px `--border` / 状態色は文言を併記・プリズム装飾は印刷しない / 見出し直後の孤立行を避ける（`break-after: avoid`）

## 9. P3 メディア・エディタ

地図・リッチテキスト・動画プレイヤー・コードエディタは共通は「静かな枠・薄いツール帯」のトーンのみ。UI クロムにプリズムを使わない。

- 地図: クロムは `--mute`/`--border`。目立つマーカー色・プリズムピン禁止。タイル・クラスタ・経路の細部は案件ガイド
- リッチテキスト: 本文は Sora / Noto Sans JP・ツールバーは bone 帯・押下 `--accent-soft`・派手なカラーピッカー禁止。コマンドセットは案件ガイド
- 動画: コントロールは Ink 帯の上に bone 系アイコン（線 1.5）・進捗は無彩色・オーバーレイ広告や派手なエンドカードは共通ガイド外
- コードエディタ: JetBrains Mono・ガターは bone + `--mute` 行番号・シンタックスは `--ink`/`--mute` の最小対比・原色ハイライト禁止
- 独自ウィジェット: 共通ガイドに置かない。そのプロダクト / 案件のガイドで定義する。共有化したいときは先に共通ガイドへ提案する

## 10. Do / Don't まとめ

Do: 背景 bone・カード surface・区切り border / 主操作は accent / プリズムはロゴとキービジュアルだけ / 状態はアイコン＋文言＋くすんだ状態色 / ライト・ダーク両方で確認 / サイズはスケールのトークンから選ぶ / 本文 16px Regular。

Don't: ボタン・リンク・フォームにプリズム / 鮮やかな原色の状態色 / プロダクトごとの独自パレット / mute を長文本文に / 色だけで意味を伝える / ナビ・リンクまで SemiBold / OFL 以外のフォント / ガイドにない部品・モーション / 背景・大きな面に `#000` / `#000000` / OS・ブラウザ標準のままのスイッチ・スライダー / 4 トークン外の色（ピンク・ローズ等）の状態バッジ。
