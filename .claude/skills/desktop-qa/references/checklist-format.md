# qa/desktop-checklist.md の書き方

対象リポジトリに置く。desktop-qa はこのファイルの上から順に 1 項目ずつ確かめる。

```markdown
# <アプリ名> デスクトップ QA チェックリスト（Windows）

## 前提
- 入れ方: <インストーラー名・CI の成果物名・既存版を上書きするか>
- 置き場: <インストール先・データ・設定・部品のフォルダー>
- 片づけで消すもの: <QA で増えたら消してよいもの>
- 消さないもの: <利用者のデータ・設定>

## 項目

### 1. <短い題>
- 手順: <操作。画面の文言はそのまま書く>
- 期待: <OK と言える観察結果。数値・文言・ファイル名で>
- 証拠: <スクショ / UI ツリー / コマンド出力 のどれで示すか>
- 注意: <押してはいけないボタン・データの扱いなど（任意）>
```

- 「期待」は見て判定できる形にする（「正しく動く」ではなく「進み具合が 0→100% で表示され、完了後に `ollama.exe` がある」）。
- 版や PR に固有の値（タイムアウト秒・既定の設定値など）は、仕様書の該当箇所を「期待」に引いておく。値が変わったらチェックリストも直す。
- 実機で確かめられないもの（他の OS・ARM など）は項目にしないか、「注意」に未確認になると書く。
