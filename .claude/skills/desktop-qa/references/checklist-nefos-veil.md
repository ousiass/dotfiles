# 例: Nefos Veil デスクトップ QA チェックリスト（Windows）

nefos-veil の安全の要件（FR-M-01「AI 変換中」ラベル、2.3 の出力表「素顔・生声を出さない」、FR-D-03 仮想デバイス名）を実機で確かめる項目。
対象リポジトリの `qa/desktop-checklist.md` の下書きに使う。値は `docs/requirements/functional.md`・`docs/architecture/overview.md` を正とする。

## 前提
- 入れ方: CI の成果物 `nefos-veil-windows-amd64`。インストーラーは softcam の登録と VB-CABLE の導入で管理者権限（UAC）が要る。UAC は puppet-remo から押せないので、悠太さんに押してもらう。既存の Nefos Veil があれば上書きし、元の版を記録する。
- 置き場: `%LOCALAPPDATA%\NefosVeil\`（パック・持ち込み・ログ）、仮想カメラ softcam、仮想マイク VB-CABLE。
- 片づけで消すもの: QA で新しく入れた場合だけ、アンインストール（仮想デバイスの登録解除と `%LOCALAPPDATA%\NefosVeil\` の削除を選ぶ）。VB-CABLE が QA 前からあったなら残す。
- 消さないもの: 悠太さんが持ち込んだ顔・声、もとからあった VB-CABLE。
- 注意: 実カメラに悠太さんの顔が映る。スクショは仮想カメラの出力側（アプリのプレビュー・カメラアプリ）だけ撮り、実カメラの生の映像は撮らない。スクショは `~/0_<pane>-qa/` の外に出さない。会議ツールで発信・参加しない。

## 項目

### 1. 「AI 変換中」ラベルが出ている
- 手順: 顔と声を選んで変換を開始し、変換中・顔ロスト（カメラの前から外れる）・待機の各状態で仮想カメラの出力を見る（Windows の「カメラ」アプリで「Nefos Veil 合成カメラ（AI 変換中）」を選ぶ）。
- 期待: どの状態でも出力の決まった位置に「AI 変換中」ラベルがある。設定画面にラベルを消す・動かす項目が無い（MVP ではサイズ・位置も固定）。
- 証拠: 状態ごとの出力のスクショ（3 枚）、設定画面のスクショ。

### 2. 素顔が映っていない
- 手順: 項目 1 の各状態に加え、停止中・変換開始直後・エンジンを止めたとき（アプリの停止操作、またはエンジンのプロセスを終了）の仮想カメラ出力を見る。
- 期待: 出力は合成の顔・待機画面「一時停止中（AI 変換）」・黒のどれかで、実カメラの素顔が 1 フレームも出ない。エンジン停止後は最後の映像を出し続けず黒になる（強制終了なら約 0.5〜0.6 秒後）。
- 証拠: 状態ごとの出力のスクショ。素顔が出た場合は、そのスクショを残さず「NG・素顔が出た状態と時刻」を文で記録し、悠太さんに見せて削除する。

### 3. 仮想デバイスの名前
- 手順: デバイスの一覧を読む。
  `Get-PnpDevice -Class Camera,Image -PresentOnly | Select FriendlyName,Status`、
  `Get-PnpDevice -Class AudioEndpoint -PresentOnly | Select FriendlyName,Status`。
  あわせて、アプリのデバイス選択と Windows の「カメラ」アプリのカメラ切り替えで名前を見る。
- 期待: 仮想カメラが「Nefos Veil 合成カメラ（AI 変換中）」。仮想マイクは VB-CABLE の標準名「CABLE Input」「CABLE Output」（改名しない。合成であることはラベル・透かし・来歴で示す）。本物のカメラ・マイクに似せた名前の仮想デバイスが無い。
- 証拠: コマンド出力、選択画面のスクショ。
