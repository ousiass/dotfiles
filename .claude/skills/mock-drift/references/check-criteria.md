# mock-drift チェック観点

## 構造（HTML モック）

| 観点 | チェック内容 |
|------|-----------|
| **主要 DOM 要素** | heading, button, form, input, list, table 等のモック定義要素が実装に存在するか |
| **テキスト/ラベル** | 表示テキスト・placeholder・alt・aria-label がモックと実装で一致するか |
| **階層関係** | 親子・兄弟関係が保たれているか。過度なネスト増加がないか |
| **要素数** | リスト・カード等の反復要素の初期表示数がモックと一致するか |
| **状態表現** | disabled / loading / empty / error の各状態がモックに描かれていれば実装にも存在するか |
| **フォーム要素** | input type, required, name, autocomplete 属性がモックの意図と一致するか |
| **リンク・遷移** | href, target, ボタンの遷移先がモックと一致するか |
| **セマンティクス** | モックで使われている見出しレベル・landmark（`main`, `nav`, `aside` 等）が実装で保たれているか |

## ナビゲーション / メニュー

| 観点 | チェック内容 |
|------|-----------|
| **メニュー項目の網羅** | モックに描かれたメニュー項目（ヘッダー・サイドバー・フッター・ドロワー）が実装にすべて存在するか。欠落・余剰がないか |
| **項目の順序** | メニュー項目の並び順がモックと一致するか |
| **ラベル** | 各項目のテキスト・アイコンがモックと一致するか。翻訳キー参照時も表示文言を確認 |
| **リンク先** | 各項目の `href` / route がモックの遷移先と一致するか |
| **サブメニュー階層** | ドロップダウン・アコーディオン等の階層構造・ネスト深度がモックと一致するか |
| **アクティブ状態** | 現在ページを示すアクティブスタイル（`aria-current`, active クラス）が実装されているか |
| **モバイル対応** | ハンバーガーメニュー・ドロワーの開閉・オーバーレイがモックと一致するか |
| **パンくず** | breadcrumb の階層・区切り文字がモックと一致するか |
| **バッジ / 通知** | 未読数・バッジ等の付随要素がモックに描かれていれば実装にも存在するか |
| **アクセシビリティ** | `role="navigation"` / `aria-label` / キーボード操作（矢印キー・Esc）がモックの意図する挙動と整合するか |

## 構造（Markdown モック）

| 観点 | チェック内容 |
|------|-----------|
| **UI 要素の列挙** | 見出し・箇条書きで記述された UI 要素が実装に存在するか |
| **Props / バリアント** | 記載された Props 名・型・バリアント名が実装と一致するか |
| **状態一覧** | 記載された状態（default / hover / active / disabled 等）が実装で表現されているか |
| **相互作用** | 記載された動作（クリック時の挙動・バリデーション等）が実装されているか |

## デザイントークン

| 観点 | チェック内容 |
|------|-----------|
| **カラー** | モックのカラー値が実装のトークン/CSS 変数に置き換わっているか。ハードコード（`#xxx`, `rgb()`）がないか |
| **タイポグラフィ** | font-family, font-size, font-weight, line-height がモックと一致し、トークン化されているか |
| **スペーシング** | margin, padding, gap がモックと一致し、spacing スケールを使用しているか |
| **角丸** | border-radius がモックと一致し、radius トークンを使用しているか |
| **シャドウ** | box-shadow がモックと一致し、shadow トークンを使用しているか |
| **境界線** | border 色・幅・スタイルがモックと一致するか |
| **アイコン** | アイコンの種類・サイズがモックと一致するか |
| **レイアウト** | flex/grid の方向・折返し・整列がモックと一致するか |

## 対応関係

| 状況 | 記録方法 |
|------|--------|
| モック → 実装なし | 「未実装」として 🔴 Critical で記録 |
| 実装 → モックなし | 「モック外の追加実装」として 🟠 Important で記録（意図的な追加ならモック更新を提案） |
| 対応するが乖離あり | 重大度基準に従い分類 |
| 完全一致 | チェック済みとして記録（レポート本文には含めない） |
