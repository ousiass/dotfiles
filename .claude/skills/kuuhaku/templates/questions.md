# 疑問テンプレート（正本）

各画面フォルダの `疑問.md` の雛形。**このファイルはコピー元。ここに疑問を書かない。**

新しい画面で初めて疑問を書くとき、下の「テンプレ本体」を `<画面フォルダ>/疑問.md` にコピーして使う。

## この往復が kuuhaku の中核

理解.html を読んで終わりにすると、分からなかった箇所がそのまま残る。
書き出して回答をもらうところまでやって初めて「教えてくれる存在」として機能する。

**疑問は3つの行き先に分かれる。**

| 行き先 | 条件 | 次の一手 |
|---|---|---|
| **解決** | 仕様書・コードを読めば答えが出た | 回答を読んで終わり |
| **穴候補に昇格** | **答えが仕様のどこにも書かれていなかった** | 理解.html §10 の表に追記する |
| **人に聞く** | 過去の判断理由が絡む／複数案のどれも成立する | 誰に何を聞くかの文案を作る |

2番目が重要。**疑問から穴が見つかる。** 「自分が分からなかった」と「仕様に書かれていない」は別のことなので、回答の過程でどちらかを判定する。

# テンプレ本体（ここから下をコピー）

```markdown
# P-0XX <画面名> — 疑問

[理解.html](理解.html) を読みながら出た疑問と、その回答。

> 使い方: 理解.html の右下キャラか §12 から「書き出す」でMarkdownをコピーし、「未回答」へ貼る。
> CCに「疑問に答えて」と言うと未回答のものに回答が入る。
> 回答を読んだら状態を付ける（解決 / 穴候補へ昇格 / 人に聞く）。

## 未回答

<!-- 書き出したMarkdownをここに貼る。CCがここを読んで回答を書く -->

## 回答済み

### YYYY-MM-DD §セクション名

**疑問**:

**CCの回答**:

**根拠**: <!-- ファイル:行。読めなかった場合は「確認できず」と書く -->

**残る不明点 / 人に聞くこと**:

**状態**: 解決 / **穴候補へ昇格**（→ §10に追記済み） / 人に聞く

```
