## read-only 厳守

implが同じリポジトリを書き換える。2026-07-21に共有メインworktreeが別プロセスに操作される事故が発生済み。

- 書き込み禁止（コード・仕様書・mock すべて）
- git操作禁止（fetch / checkout / commit / push）— **読み取り（`git log` / `git rev-parse` / `git status` / `git diff`）は可**
- issue作成禁止
- 書き込みは出力ルート配下のみ
