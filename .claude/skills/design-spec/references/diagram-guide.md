# デザイン仕様書 図表ガイド

ドキュメント内の図表はすべて Mermaid 記法（` ```mermaid ` コードブロック）で記述する。

## ドキュメント別の図の種類

| ドキュメント | 使用する図の種類 | Mermaid 記法 |
|------------|---------------|-------------|
| **画面設計** | 画面遷移図、ワイヤーフレーム構成 | `stateDiagram-v2` / `graph TD` |
| **コンポーネント仕様** | コンポーネントツリー、依存関係 | `graph TD` |
| **デザイントークン** | カラーパレット構成、スケール図 | テーブル形式（図は不要な場合が多い） |
| **インタラクション仕様** | 状態遷移図、操作フロー | `stateDiagram-v2` / `sequenceDiagram` |

## 画面モックアップの記法

Mermaid では表現しきれないレイアウトには ASCII アートを使う。

```
┌─────────────────────────────────────┐
│  [Logo]          [Nav1] [Nav2] [◯]  │  ← ヘッダー
├─────────────────────────────────────┤
│  ┌──────────┐  ┌──────────────────┐ │
│  │ サイドバー │  │  メインコンテンツ   │ │
│  │          │  │                  │ │
│  │ - Menu1  │  │  ┌────┐ ┌────┐  │ │
│  │ - Menu2  │  │  │Card│ │Card│  │ │
│  │ - Menu3  │  │  └────┘ └────┘  │ │
│  └──────────┘  └──────────────────┘ │
├─────────────────────────────────────┤
│  © Footer                           │
└─────────────────────────────────────┘
```

### ASCII モックアップの凡例

| 記号 | 意味 |
|-----|------|
| `[ ]` | ボタン / クリッカブル要素 |
| `( )` | 入力フィールド |
| `┌─┐` | コンテナ / カード |
| `───` | 区切り線 |
| `◯` | アイコン / アバター |
| `...` | 省略 / 繰り返し |

## コンポーネント状態の表現

```mermaid
stateDiagram-v2
    [*] --> Default
    Default --> Hover: マウスオーバー
    Default --> Focused: Tab/クリック
    Hover --> Active: クリック中
    Focused --> Active: Enter/Space
    Active --> Default: リリース
    Default --> Disabled: disabled=true
```

## レスポンシブブレークポイントの表現

テーブル形式で記載する：

| ブレークポイント | 幅 | レイアウト変更点 |
|---------------|---|---------------|
| Mobile | < 640px | 1カラム、ハンバーガーメニュー |
| Tablet | 640-1024px | 2カラム、サイドバー折りたたみ |
| Desktop | > 1024px | 3カラム、サイドバー常時表示 |

## 改訂履歴フォーマット

すべてのドキュメントの末尾に以下の形式で改訂履歴を記載する：

```markdown
## 改訂履歴

| 版 | 日付 | 変更内容 | 変更理由 |
|---|------|---------|---------|
| 1.0 | YYYY-MM-DD | 初版作成 | — |
```

- 新規作成時は `1.0` から開始
- 追記・更新時はマイナーバージョンを上げる（1.1, 1.2, ...）
- 構成の大幅な変更はメジャーバージョンを上げる（2.0, 3.0, ...）
