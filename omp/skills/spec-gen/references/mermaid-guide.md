# Mermaid 図表ガイド

ドキュメント内の図表はすべて Mermaid 記法（` ```mermaid ` コードブロック）で記述する。
GitHub 上で自動レンダリングされ、テキストとして差分管理もできる。

## ドキュメント別の図の種類

| ドキュメント | 使用する図の種類 | Mermaid 記法 |
|------------|---------------|-------------|
| **機能要件** | ユースケース図、画面遷移図 | `graph TD` / `stateDiagram-v2` |
| **アーキテクチャ設計** | システム構成図、通信フロー | `graph TD` / `sequenceDiagram` |
| **ER / データモデル** | 全体ER図 + テーブル別ER図 | `erDiagram` |
| **API 仕様** | リクエストフロー、認証フロー | `sequenceDiagram` |
| **コンポーネント設計** | コンポーネント依存関係図 | `graph TD` |

## ER / データモデルの図表構成

ER ドキュメントには必ず以下の2種類の図を含める：

1. **全体ER図**: すべてのテーブルとリレーションを1つの `erDiagram` で俯瞰。カラムは含めずテーブル名とリレーションのみ
2. **テーブル別ER図**: テーブルごとに個別の `erDiagram` を作成。カラム名・型・制約を詳細に記述。関連テーブルとのリレーションも含める

```markdown
<!-- ドキュメントの構成例 -->

## 全体ER図
<!-- すべてのテーブルとリレーションを俯瞰 -->

## テーブル定義

### users
<!-- users テーブルの詳細ER図 + カラム定義表 + インデックス -->

### posts
<!-- posts テーブルの詳細ER図 + カラム定義表 + インデックス -->
```

## 注意事項

- 図が不要なドキュメント（非機能要件など）では無理に図を入れない
- 既存ドキュメントが別の図表形式（PlantUML 等）を使っている場合はそれに合わせる

## 改訂履歴フォーマット

すべてのドキュメントの末尾に以下の形式で改訂履歴を記載する：

```markdown
## 改訂履歴

| 版 | 日付 | 変更内容 | 変更理由 |
|---|------|---------|---------|
| 1.0 | YYYY-MM-DD | 初版作成 | — |
| 1.1 | YYYY-MM-DD | ○○のエンドポイントを追加 | ○○機能の追加に伴い |
```

- 新規作成時は `1.0` から開始
- 追記・更新時はマイナーバージョンを上げる（1.1, 1.2, ...）
- 構成の大幅な変更はメジャーバージョンを上げる（2.0, 3.0, ...）
