# デザインレビューチェック項目

## 視覚的一貫性

| チェック項目 | 基準 |
|------------|------|
| **カラー** | デザイントークン / テーマ変数を使用しているか。ハードコードされた色値（`#xxx`, `rgb()`）がないか |
| **タイポグラフィ** | フォントサイズ・ウェイト・行間がデザインシステムのスケールに準拠しているか |
| **スペーシング** | マージン・パディングがデザインシステムのスペーシングスケールを使用しているか |
| **角丸・シャドウ** | border-radius, box-shadow がトークン化された値を使用しているか |
| **アイコン** | サイズ・色・スタイルが統一されているか。アイコンライブラリが一貫しているか |

## レイアウト・レスポンシブ

| チェック項目 | 基準 |
|------------|------|
| **レイアウト手法** | Flexbox / Grid が適切に使われているか。不要なネストがないか |
| **ブレークポイント** | レスポンシブ対応がプロジェクトの基準に沿っているか |
| **コンテナ幅** | max-width 制約が適切に設定されているか |
| **オーバーフロー** | テキストの折り返し・省略、スクロール領域が適切に処理されているか |
| **最小・最大サイズ** | コンテンツ量の増減でレイアウトが崩れないか |

## アクセシビリティ

| チェック項目 | 基準 |
|------------|------|
| **コントラスト比** | テキストと背景のコントラストが WCAG AA 基準（4.5:1 / 3:1）を満たしているか |
| **フォーカス表示** | インタラクティブ要素にフォーカスインジケータがあるか。`outline: none` のみで代替なしになっていないか |
| **ARIA** | 適切な role, aria-label, aria-describedby が付与されているか |
| **キーボード操作** | Tab 順序が論理的か。カスタム UI がキーボードで操作可能か |
| **alt テキスト** | 画像に適切な alt 属性があるか。装飾画像は `alt=""` か `aria-hidden` か |
| **セマンティクス** | div/span の乱用がないか。見出しレベルが適切か |

## インタラクション

| チェック項目 | 基準 |
|------------|------|
| **状態表現** | hover / focus / active / disabled の各状態にスタイルがあるか |
| **ローディング状態** | 非同期処理にローディング表示があるか。スケルトン / スピナーが適切か |
| **エラー状態** | フォームバリデーション、API エラーの表示が適切か |
| **空状態** | データが 0 件の場合に適切なメッセージや UI が表示されるか |
| **トランジション** | 状態変化にアニメーションが適切に付いているか。`prefers-reduced-motion` への対応 |
| **フィードバック** | ユーザー操作に対して視覚的フィードバックがあるか（ボタン押下、フォーム送信等） |

## コンポーネント API 設計

| チェック項目 | 基準 |
|------------|------|
| **Props 設計** | Props 名が直感的で他コンポーネントと一貫しているか |
| **バリアント** | size / color / variant が体系的に設計されているか |
| **合成パターン** | children / slot を活用した柔軟な構成ができるか |
| **デフォルト値** | 適切なデフォルト値が設定されているか |
| **型安全性** | デザインバリアント（size, color 等）がリテラル型で制約されているか |
