# ドキュメント反映が必要なコード変更のチェック観点

| カテゴリ | ドキュメント反映が必要な変更 |
|---------|--------------------------|
| **API / インターフェース** | エンドポイントの追加・変更・削除、関数シグネチャ変更、CLI引数変更、レスポンス形式変更 |
| **データモデル** | テーブル・カラムの追加・変更・削除、リレーション変更、マイグレーション追加 |
| **設定・環境変数** | 環境変数の追加・変更・削除、設定ファイル形式変更、デフォルト値変更 |
| **ディレクトリ構成** | ファイル・ディレクトリの追加・移動・削除・リネーム |
| **依存関係** | ライブラリの追加・削除・バージョン変更 |
| **機能** | 新機能追加、既存機能の動作変更、機能の廃止・削除 |
| **セットアップ / ビルド** | インストール手順変更、ビルドコマンド変更、デプロイ設定変更 |
| **認証・認可** | ロール・権限変更、認証フロー変更 |
| **エラー処理** | エラーコード・ステータスコードの追加・変更 |
